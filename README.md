🎬 DhakaFlix Mobile

Your Local DhakaFlix Entertainment Experience.

DhakaFlix is an Android application dedicated exclusively to accessing and streaming content from DhakaFlix (Local Dhaka Media Server).

It brings a familiar streaming-platform experience to Android smartphones, featuring a modern dark interface, featured content, movie and TV series browsing, searchable media libraries, and convenient playback options.

DhakaFlix is designed specifically for the DhakaFlix local media ecosystem. It is not a general-purpose media player or a client for third-party media servers.

---

📱 Features

- 📱 Mobile-first Android interface
- 🎨 Netflix-inspired dark design
- 🏠 Featured content and horizontal media shelves
- 🔎 Media search
- 🎬 Movie browsing
- 📺 TV series browsing
- ▶️ In-app media playback
- 🎞️ VLC external player option
- 💾 Watch progress support
- ⚙️ Application settings
- 🌐 Access to DhakaFlix (Local Dhaka Media Server)

🎯 Supported Media Platform

DhakaFlix (Local Dhaka Media Server)

The application is specifically designed to work with DhakaFlix's local media platform.

It does not offer general-purpose support for:

- Third-party FTP servers
- Arbitrary HTTP media directories
- Other ISP media servers
- Unrelated streaming platforms

📺 DhakaFlix TV

A separate Android TV application experience dedicated to DhakaFlix (Local Dhaka Media Server).

Designed for television screens and Android TV devices.
