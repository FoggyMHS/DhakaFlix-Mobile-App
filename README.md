🎬 DhakaFlix

Your Local DhakaFlix Entertainment Experience

DhakaFlix is an Android entertainment application built exclusively for DhakaFlix (Local Dhaka Media Server).

It provides a convenient way to browse and watch the movies and TV series available through the DhakaFlix local media platform.

DhakaFlix is designed specifically for this media ecosystem. It is not a general-purpose media player or a client for unrelated media servers.

---

📱 DhakaFlix Mobile

The mobile application is designed for Android smartphones, with a modern dark interface and convenient media browsing.

Features

- Modern, Netflix-inspired dark interface
- Featured content and media shelves
- Movie browsing
- TV series browsing
- Media search
- In-app media playback
- VLC external player option
- Watch progress support
- Application settings
- Access to DhakaFlix (Local Dhaka Media Server)

📺 DhakaFlix TV

DhakaFlix TV is a separate Android TV application dedicated to the same DhakaFlix local media platform.

It provides a television-oriented experience for compatible Android TV devices.

---

🎯 Supported Media Platform

DhakaFlix (Local Dhaka Media Server)

Both applications are specifically intended for this platform.

They are not designed to connect to arbitrary FTP servers, generic HTTP media directories, other ISP media servers, or unrelated streaming services.

⚙️ Building with GitHub Actions

Both Android applications can be built using GitHub Actions.

1. Open the repository's Actions tab.
2. Select Build DhakaFlix Mobile or Build DhakaFlix Android TV.
3. Select Run workflow.
4. Choose whether to publish a GitHub Release.
5. Start the workflow.
6. Download the generated APK from the workflow's Artifacts section.

A GitHub Release is optional. You can download the build artifact without publishing a release.

The mobile workflow generates a debug APK. The TV workflow generates a release APK using the TV project's release configuration.
